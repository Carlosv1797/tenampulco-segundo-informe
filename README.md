# Segundo Informe de Gobierno de Tenampulco

Invitación web basada en el PDF aprobado. Domingo 18 de octubre de 2026, 12:00 hrs, Teatro del Pueblo, Miguel Hidalgo 14, Centro, 73500, Tenampulco, Puebla.

## Funciones

- Diseño adaptable a celular y computadora.
- Cuenta regresiva en vivo, usando la fecha y hora de Tenampulco (UTC−06:00).
- Ventana emergente de registro con nombre completo, cargo e institución.
- Validación de campos y resumen antes de finalizar.
- Mensaje prellenado para WhatsApp de la organización, 7841235717.
- Enlace al mapa.

El visitante debe pulsar **Enviar** en WhatsApp. La página prepara el mensaje y no puede verificar que se haya enviado. Esta versión para GitHub Pages no guarda una base central de asistentes: las confirmaciones llegan a la conversación de WhatsApp de la organización. No se almacenan datos personales en este repositorio.

## Publicar

`index.html` es autónomo: incluye las imágenes, los estilos y la interacción. Se puede publicar directamente con GitHub Pages, usando la rama `main` y la carpeta raíz.

## Modificar

Editar `index.template.html` y ejecutar `build.py` para generar `index.html`. El logo mejorado se conserva como imagen; los textos y el formulario son HTML.
